## 📊 **CSV IMPORT GUIDE** (Admin)

### Import Customers in Bulk:

1. **Download Template**
   - Go to: Admin → Customers
   - Click "Import CSV/Excel"
   - Download template CSV

2. **Fill Customer Data**
   ```csv
   name,phone,email,isMember
   Siti Aminah,0123456789,siti@example.com,true
   Nur Aisyah,0198765432,nur@example.com,false
   ```

3. **Upload File**
   - Select filled CSV/Excel
   - Click Upload
   - Review validation
   - Import confirmed!

4. **Notes**:
   - Phone format: 01xxxxxxxx
   - Email optional
   - Default password = phone number
   - System validates duplicates
